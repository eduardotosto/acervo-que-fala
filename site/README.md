# Acervo que Fala

Descrições de acessibilidade em dois níveis para objetos do acervo digital do Museu do Índio,
geradas por modelos abertos e avaliadas objeto a objeto.

Este Space serve um lote pré-computado de 50 objetos: nenhum modelo roda aqui. Os textos são
gerados por modelo, sem revisão humana, e contêm erros que a avaliação aponta.

Projeto acadêmico independente (ICA/PUC-Rio). Não é um produto do Museu do Índio.

Código, dados e avaliação: https://github.com/eduardotosto/acervo-que-fala
